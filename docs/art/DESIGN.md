# README art: Toybox

THESIS: the before/after of a brick build, shown as a toy. Refuses the grey dev-tool banner and the terminal screenshot.
WORLD: a builder in Studio watching a part counter climb. Toy colours on a yellow (#FFCF2E) ground, ink #17140F, bricks #E5392A / #2F6BFF / #3DBE5B / #9AA0A6.
STORY: hero (many parts in, one mesh out) → steps (what happens, 1-2-3) → x-ray band on ink (what gets removed) → tables for install and settings.
FIRST VIEWPORT: hero.png at 1600×1000 CSS px (2x PNG); the h1 is Bricolage Grotesque 800 at 124px over 2 lines, with the builds in the lower 60% and 30px captions.
SIGNATURE: the same example house drawn as exploded Parts, as an x-ray and as one mesh. Every count is computed from that house (`iso.js`: stats, quads).
TYPE: Bricolage Grotesque 800 (display) + Atkinson Hyperlegible 400/700 (text). No mono.
REFUSES: a logo, badges, emoji headings, invented benchmarks.
